# Video Editor Golden Workflows

These fixtures are deterministic routing/regression examples for AI-Verse Video Editor.

They are not media assets and they do not substitute for encoded-media acceptance.

`golden-fixtures.json` covers the representative requests required by the canonical implementation plan:

- full raw talking-head edit;
- silence-only cleanup;
- mistake/retake cleanup;
- short-form Reel;
- long-form visual explainer;
- website-to-video promo;
- motion-graphics-only edit;
- reference-led edit;
- three prototype visual directions.

The release test verifies each fixture against the canonical orchestration graph and the bounded Interface Designer handoff contract.
