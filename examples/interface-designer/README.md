# Interface Designer Golden Fixtures

These fixtures are maintainer regression examples for AI-Verse Interface Designer.

They are not templates to copy into member products.

Each fixture locks the expected:

- scope classification;
- delivery target;
- specialist families;
- `DESIGN.md` persistence decision;
- major orchestration stages;
- rendered QA expectations.

The five fixtures intentionally cover different interface jobs:

1. full dashboard workflow;
2. exact reference recreation;
3. interaction-heavy component;
4. immersive scroll experience;
5. mobile/Expo interaction.

Canonical data lives in `golden-fixtures.json`.

Tests verify that every expected scope, target, stage and expert still resolves against the current Interface Designer graph and registry.
