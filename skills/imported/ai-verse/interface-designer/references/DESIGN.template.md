# Brand & Product Principles

Describe the stable personality, hierarchy, density and visual philosophy.

# Color Roles / Tokens

Define semantic color roles and any stable tokens actually used by the product.

# Typography

Define family, hierarchy, type scale, weights, tracking and leading that must persist.

# Layout & Spacing

Define grid, gutters, containers, spacing rhythm and density.

# Radii, Elevation & Surfaces

Define border, radius, shadow, glass, elevation and surface hierarchy.

# Navigation / Information Architecture Grammar

Define the stable shell, navigation behavior and major layout grammar.

# Components & Reusable UI Rules

Record product-wide component rules that future work should preserve.

# Interaction Language

Record interaction principles, gestures, disclosure patterns, sheets/drawers and focus behavior.

# Motion Language

Define duration/physics/easing rules, continuity principles and reduced-motion behavior.

# Responsive & Mobile Direction

Define intentional mobile hierarchy, navigation, touch targets, safe areas and breakpoint behavior.

# Accessibility Requirements

Record persistent accessibility constraints for the product.

# Signature Interaction

Include only when one intentionally exists.

# Forbidden Patterns / Product-Specific Anti-Patterns

Record recurring product-specific patterns that should not reappear.
