# AI-Verse Video Editor Ownership Boundary

## Video Editor owns

- task classification and pipeline orchestration;
- source/provenance intake;
- edit-state continuity;
- EDL and source-time integrity at the orchestration boundary;
- selection of short-form versus long-form editorial specialists;
- selection of verification gates;
- final completion claim based on real media evidence.

## Nate-derived editorial specialists own

- deterministic silence-edit procedure;
- reviewed mistake, retake and stutter decisions;
- short-form hook/open-loop/payoff structure;
- long-form visual storytelling methodology;
- editorial motion-beat planning;
- Nate-specific website-to-video workflow where selected.

These specialists remain separately attributable and testable.

## HyperFrames provider owns

- current composition/runtime contract;
- supported timing/data attributes;
- current CLI behavior;
- lint and `check`;
- Studio/preview mechanics;
- registry mechanics;
- deterministic render behavior;
- current GSAP integration rules;
- encoded render mechanics.

The provider does not decide what words or story beats should be removed.

## FFmpeg specialist owns

Bounded media operations such as transcoding, mux/demux, probing, extraction and preprocessing when selected.

It does not become the editorial authority.

## Interface Designer owns only a conditional visual handoff

May contribute:

- visual direction;
- typography;
- layout/composition;
- design-system thinking;
- reference reconstruction;
- prototype visual directions;
- general motion taste that does not conflict with the renderer.

It does not own transcript truth, EDLs, editorial cuts, source-time mapping, audio sync, HyperFrames correctness or final video acceptance.

## Existing NLE specialists

Premiere Agent and After Effects Assistant remain optional separate backends/specialists.

Video Editor may coordinate them when the user explicitly wants those environments or a task materially benefits from them. They are not silently replaced by HyperFrames.

## Conflict resolution

1. user instruction;
2. source/provenance truth;
3. established project/locked edit decisions;
4. editorial specialist authority;
5. HyperFrames/runtime correctness;
6. media QA evidence;
7. visual-design specialist advice;
8. optional polish.
