# Changelog

## 1.0.0 — 2026-10-03

Initial public release of **AI-Verse Cinematic Realism Director**.

### Added

- Beginner-first **AUTO DIRECT** workflow from one-sentence prompts.
- Expert **MANUAL CAMERA** workflow with explicit technical locks.
- **CINEMATIZE**, **REALITY REPAIR**, **REFERENCE MATCH**, and **PROMPT ONLY** workflows.
- Provider-neutral Cinematic Shot Spec, realism diagnosis, and reference-DNA schemas.
- Cinematography knowledge for composition, capture formats, lens character, focal length/perspective, aperture/depth, and still-frame motion.
- Motivated-lighting, exposure, film/sensor response, color, and restrained texture systems.
- Physical-realism systems for skin, hair, eyes, fabric, materials, contact, gravity, reflections, and shadows.
- Reusable Reality Gate for photographic plausibility and anti-AI verification.
- Provider adapters for Generic, OpenAI Images, Gemini, Seedream, FLUX, Magnific Cinematic, and Higgsfield Soul Cinema.
- Progressive disclosure and question-minimization policies.
- Standalone package operation with no required sibling skill, MCP, API key, or AI-Verse OS dependency for prompt/spec use.
- Behavioral evals for routing, beginner AUTO, expert locks, Reality Repair, Reference Match, provider consistency, anti-cliche behavior, physical plausibility, adversarial boundaries, and regression coverage.
- Controlled Magnific/Higgsfield benchmark protocol; no superiority claim without repeated matched evidence.
- Repository integration, isolated-copy, runtime-adapter materialization, and deterministic admission/security tests.

### Invariants

- Explicit user values remain locks.
- AUTO fills only missing decisions.
- Provider syntax stays downstream of the universal shot design.
- Perspective is not inferred from focal length alone.
- Cinematic does not automatically imply shallow depth, grain, flare, haze, rim light, anamorphic artifacts, or teal/orange grading.
- Reference observations are not exact hardware facts without evidence.
- Preserve before transforming.
- Tool/API success is not visual verification.

### Scope

Cinematic Realism Director is a still-image cinematic direction and realism skill. Temporal video editing, timeline operations, lip-sync, and motion choreography remain outside its primary authority.
