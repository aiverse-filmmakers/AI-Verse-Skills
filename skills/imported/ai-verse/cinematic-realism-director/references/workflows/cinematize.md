# CINEMATIZE Workflow

Status: RUNTIME WORKFLOW

Purpose: upgrade an existing idea or ordinary prompt into a world-class professional photographic/cinematic still while preserving the concept and requested medium.

Use with:

- `references/professional-quality-floor.md`
- `references/execution-priority.md`
- `references/reality-gate.md`

## Entry

Use when the user already has a concept/prompt and asks to make it more cinematic, professional, realistic, photographic, film-like, better directed, or visually stronger.

The user does not need to know what technical ingredients are missing.

## Preservation Rule

Separate:

```text
PRESERVE
concept
subject / action
identity / product
required environment
requested medium
explicit style / technical / cleanliness / provider locks

AUTO-UPGRADE
professional specialty
shot design / timing
camera position / hierarchy
optics / depth
lighting
exposure / tonal response
color / grade
subtle base texture
materials / contact / reflections
physical realism
```

Professionalization must not erase the medium. An iPhone prompt stays elite mobile photography; a candid stays candid; an architectural image follows architecture discipline.

## Procedure

1. Parse literal content, requested/implicit medium, existing technical choices and preservation constraints.
2. Lock every explicit user choice.
3. Infer the correct professional specialty using `professional-quality-floor.md`.
4. Identify which layers are weak or underspecified.
5. Upgrade those layers to the Professional Quality Floor while preserving all locked content.
6. For narrative/cinematic/general photographic work without a stronger specialty signal, target feature-film-level visual hierarchy, premium tonal response, ARRI-like highlight/skin behavior as an observable target, rich readable shadows, professional color separation, realistic optical falloff and subtle organic filmic texture.
7. Replace vague prestige adjectives with visible/physical instructions rather than merely appending more adjectives.
8. Preserve anti-cliche discipline: professional finish does not require teal/orange, anamorphic streaks, haze, dramatic rim light, maximum blur, heavy halation or strong grain.
9. Resolve technical conflicts through AUTO fields before touching locks.
10. Build/update the provider-neutral Cinematic Shot Spec.
11. Run the Reality Gate at V0, including Professional Quality Floor checks.
12. Choose execution using `execution-priority.md`: explicit provider lock first; otherwise native/local first; external fallback only for a material missing capability.
13. Adapt only to the already-selected execution path.
14. Execute if requested/available, otherwise return the production-ready prompt/spec.
15. If pixels are inspectable, run V2 and repair material quality/realism failures without redesigning successful areas.

## Upgrade Priority

```text
requested medium / professional specialty
-> story / visual hierarchy
-> camera position / composition / timing
-> perspective
-> focus / depth / motion
-> lighting motivation and falloff
-> exposure / highlight rolloff / shadow density
-> color separation / grade
-> skin / materials / contact / reflections
-> subtle organic base texture
-> optional stronger effects only when justified
```

Never try to rescue weak geometry, light or material behavior with grain, haze, flare, bloom or a LUT.

## Professional Floor vs Overdirection

If the original prompt is already precise and professional, do not inflate it with unnecessary technical detail.

CINEMATIZE can improve quality through better causal wording, coherence and finishing rather than prompt length.

But do not interpret brevity as permission to return merely ordinary photography. The resolved image intent must still meet the Professional Quality Floor.

## Texture

For most photographic/cinematic work, retain subtle fine organic texture unless the user/medium calls for pristine/no-grain output.

This is separate from strong visible film-stock grain, halation, bloom or other overt effects.

## Output

Return or execute a version that is recognizably the same concept and medium but has stronger professional visual judgment, cinematographic/photographic causality, premium finishing and physical plausibility.

## Failure Conditions

CINEMATIZE fails if it:

- changes the concept or requested medium unnecessarily;
- silently changes locks;
- returns merely generic/competent imagery because the original prompt was simple;
- substitutes effect stacking for professional direction;
- forces cinema-camera aesthetics onto a phone/candid/specialist-photo brief;
- drops subtle professional finishing in the name of anti-cliche restraint;
- routes to an external provider before an adequate native/local path without justification;
- automatically selects Magnific/Higgsfield for cinematic quality.
