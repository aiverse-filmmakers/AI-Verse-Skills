# AI-Verse First-Party Skills

This namespace is permanently reserved for skills authored specifically for AI-Verse.

Rules:

- Do not place third-party copied or adapted skills here.
- AI-Verse first-party skills must follow the repository skill specification.
- Future generated skills are not automatically first-party. They must pass the promotion policy first.
- Keep first-party capability separate from AI-Verse OS core authority.

Current first-party packages in this namespace include:

- `interface-designer`
- `video-editor`
- `cinematic-realism-director`

Presence in this namespace means AI-Verse first-party ownership. It does not by itself change the fixed ranked employee registry, grant runtime authority, or imply external provider access. Ranked-catalog promotion remains a separate explicit registry decision.
